\appendix
\section{Reproducible exact computation}\label{app:computation}

\subsection{Algorithms and independent checks}

All Python programs use only the standard library. A finite group is stored
as a complete integer multiplication table. Before analysis, the code checks
closure, identity, inverses, and every associativity triple. It computes the
center, verifies that commutation is constant on central cosets, and builds
the compressed graph \(\Delta_G\).

Maximum clique is solved by branch and bound with a greedy-color upper bound.
Chromatic number is solved by exact DSATUR decision searches at successive
numbers of colors. Returned clique and coloring witnesses are checked edge
by edge. When enabled for the configured small explicit groups (all except
\(E_3\)), a second cover route enumerates subgroups, retains the maximal
abelian ones, and solves an exact set-cover instance. Every selected cover
member is rechecked for subgroup closure, commutativity, and complete
coverage.

The verifier compares both optimized graph solvers with naive exhaustive
enumeration for every one of the \(33{,}868\) labeled simple graphs having at
most six vertices. It also reconstructs every saved group and certificate.
The final audit on Python 3.9.6 passed all 18 tests.

\subsection{Saved exact records}

The explicit suite includes \(S_3,D_8,Q_8,S_4\), dihedral and Heisenberg
groups, \(E_m\) for \(m\le3\), and \(D_8\times S_3\). Representative exact
values are
\[
\begin{array}{c|cccccc}
G&S_3&D_8&Q_8&E_2&E_3&D_8\times S_3\\ \hline
(\nu(G),a(G))&(4,4)&(3,3)&(3,3)&(5,5)&(7,9)&(12,12).
\end{array}
\]

GAP 4.16.0 with SmallGrp 1.5.4 exported complete multiplication tables for
all groups of orders \(8,32,64\); Python performed all subsequent graph and
cover calculations independently. For the 267 groups of order 64 the exact
distribution was
\[
\begin{array}{c|rrrrrrrr}
(\nu,a)&(1,1)&(3,3)&(5,5)&(6,6)&(7,7)&(9,9)&(11,11)&(17,17)\\ \hline
\#&11&31&72&38&10&69&33&3.
\end{array}
\]
Every one of these records has a clique and a same-size coloring, together
with a checked abelian-subgroup cover. This bounded census found no
\(a>\nu\); it is not evidence of equality in general, since \(E_3\) and
\(S(3,2)\) already have \(a>\nu\).

A separate cutoff scan inspected all 2,328 SmallGroups of order 128. A
checked greedy clique excluded 1,910 groups from the range \(\nu\le6\); exact
clique and coloring witnesses for all 418 survivors have distribution
\[
 (\nu,a)=(1,1)^{15},(3,3)^{60},(5,5)^{199},(6,6)^{144}.
\]
This is a bounded census, not a classification theorem.

For \(S(3,2)\), the code checks all \(14{,}348{,}907\) associativity triples,
the 81-vertex compressed graph, a seven-clique, and an independent
include/exclude exclusion of an eight-clique on 40 projective twin classes.
Exact DSATUR rejects 7, 8, and 9 colors. Independently, a ten-plane
\(\mathbb F_9/\mathbb F_3\) symplectic spread gives ten abelian subgroups of
order 27 whose union is the group.

The symmetry-reduced projective solver also certifies
\[
 (\nu(S(5,2)),a(S(5,2)))=(18,26),\qquad
 (\nu(S(3,3)),a(S(3,3)))=(13,28).
\]
For each instance, pair transitivity reduces exclusion of a larger clique to
four stabilizer-orbit cases; a dependency-free C branch-and-bound solver
checks the residual graphs, while Python independently checks the saved
clique and symplectic-spread witnesses. At \((q,m)=(7,2)\) only the rigorous
interval \(33\le\nu\le50\) is claimed.

For the exact value \(h(5)=5\), the GAP export covers all 42 quotient groups
\(Q\) of order at most 16 and all 2,986 subgroups \(K\le S'\) normal in the
chosen Schur cover \(S\twoheadrightarrow Q\). There are 2,396 distinct
labeled adjacency tuples. Exact witnesses give
\[
\begin{array}{c|rrrrrrrrrrr}
(\omega,\chi)&(1,1)&(3,3)&(4,4)&(5,5)&(6,6)&(7,7)&(8,8)&(9,9)&(11,11)&(13,13)&(15,15)\\ \hline
\#&42&84&4&234&215&22&1&1492&492&315&85.
\end{array}
\]
Thus all 364 records with \(\omega\le5\) are 5-colorable. The raw file records
the total subgroup count, retained normal-kernel count, and complete kernel
serial range for each quotient; the Python verifier checks all serial ranges,
graphs, cliques, and colorings.

For the finite leaves in the reconstructed proof of $f(6)=36$, GAP exports
165 ambient subgroup conjugacy-class records, reduced by isomorphism ID to
48 group types.  The independent verifier rebuilds 5,257 subgroups from the
complete multiplication tables, recovers every maximal subgroup, and tests
all 5,545,351 six-subsets.  It finds 100,483 covers, 10,308 irredundant
covers, and 6,678 whose intersection is core-free.  In particular,
$\operatorname{SmallGroup}(36,10)=S_3\times S_3$ has 38 covers and no
irredundant one, whereas $\operatorname{SmallGroup}(36,13)$ has 72
qualifying covers with trivial intersection.

For $h(6)$, all 162 quotient types of order at most 36 are represented.
The 161 nonexceptional types give 23,527 normal-kernel records: 18,231 have
nontrivial radical, 4,982 have a saved seven-clique, and the 314 exact
survivors have distribution
\[
 (\omega,\chi)=(1,1)^1,(3,3)^1,(4,4)^2,(5,5)^{93},(6,6)^{217}.
\]
The structural $C_2^5$ exception is redundantly checked by enumerating all
174,251 alternating-form pencils; each of the 156,240 zero-radical pencils
has a verified nine-clique.

To regenerate a SmallGroups census after building GAP at the recorded local
path, replace \(N\) by \(8\), \(32\), or \(64\) in both filenames:
\begin{verbatim}
work/gap-4.16.0/gap -l 'work/gap-4.16.0;' -q \
  -c 'ERDOS117_ORDER:=N;; ERDOS117_OUTPUT:=
  "experiments/logs/gap_smallgroups_orderN.tsv";;
  Read("experiments/configs/gap_export.g");'

PYTHONPYCACHEPREFIX=/tmp/erdos117-pycache \
python3 src/python/analyze_gap_export.py \
  --input experiments/logs/gap_smallgroups_orderN.tsv \
  --output experiments/logs/gap_smallgroups_orderN.json \
  --omit-multiplication-tables
\end{verbatim}
The omission option was used for order 64; it may be omitted at orders 8
and 32 to embed the multiplication tables in both TSV and JSON.
