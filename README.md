# Erdős Problem #117

This private repository coordinates a rigorous attempt to resolve Erdős Problem #117: determine, as sharply as possible, the largest minimum number of abelian subgroups needed to cover a group whose pairwise-noncommuting subsets have bounded size.

The project combines verified primary-source research, structural group theory, exact finite computation, graph products, and adversarial proof audit. The standing target is a complete theorem; current claims and limitations are tracked in [`STATUS.md`](STATUS.md).

## Repository map

- `literature/`: primary-source review, bibliography, claim ledger, and citation graph.
- `notes/`: definitions, reductions, bounds, strategies, failures, and proof obligations.
- `src/`: GAP, Python, and independent verification code.
- `experiments/`: versioned configurations, logs, and notebooks.
- `results/`: exact datasets, records, family formulas, and conjectures.
- `proof/`: publication manuscript, bibliography, dependency graph, and appendix.
- `audit/`: adversarial, source, computation, and release audits.

See [`AGENTS.md`](AGENTS.md) for definitions, evidence labels, proof rules, and coordination protocol.
